# Figma 原生重建

## 品牌与目标

发现当前可用 Figma 连接工具。每次调用 use_figma 前加载 `figma:figma-use`，按其要求读取 API 与品牌系统参考；整页/画布制作同时加载 `figma:figma-generate-design`。不要使用仅凭记忆的 API。创建新文件遵循 create-new-file 技能。需要新组件时加载 generate-library；本流程不默认新建品牌库。

先读取品牌文件的组件、变量、模式、文字和效果样式，保存实际来源键/节点 ID 与语义用途。检查目标文件惯例与可写权限。使用现有匹配组件与变量绑定，不能只复制看起来接近的颜色。品牌与截图若冲突：遵循用户明确的品牌优先级；未指定且影响显著时澄清，继续不受影响的重建。品牌文件本身不因参考而被修改。

## 画布与节点

- 新建独立重建画布，避免覆盖现有作品。保留原图画幅与相对坐标；文字、icon、卡片、背景和对象分组命名。海报自由排版按坐标；具有内容关系的卡片/列表/按钮依官方技能使用 Auto Layout，避免改变视觉位置。
- TEXT 节点：查询可用 font family/style，await 加载后写入，再绑定真实文字样式/变量。读回实际字体与样式绑定。混合字体逐段处理。禁止用通用默认字体冒充品牌字体。
- 图形：矩形、椭圆、线、路径优先。SVG 导入后读回 VECTOR/BOOLEAN_OPERATION 等实际结构、路径及 paints，确认没有嵌入整图。保持复杂 icon 的可编辑路径，不强求必须手动鼠标描线；Plugin API 的路径构建等效于钢笔绘制。
- 卡片：优先品牌组件实例与合法属性/Slot 内容；文字和内容仍可编辑。组件无法表达目标时创建独立可编辑结构并记录差异，不擅改 main component。
- 图像：只导入补全后的离散背景/主体/道具素材。原图只保留为产物外的对照，不能成为可见合成底图。图片传入方法服从当前官方工具能力；不能假设 use_figma 能直接 fetch 外网图片。需要捕获离散素材时按官方 generate-design 流程操作，禁止把整页捕获根作为成品。
- 效果：原生 effect、gradient、stroke，阴影与主体关系可编辑。保留透明边缘与图像真实 alpha。

## 验证与交付

返回画布及实际子节点 ID、类型、边界，逐项对照重建清单，核查文字内容/字体、矢量路径、图像节点范围、品牌绑定与组层级。不能用节点总数判断通过。

检查全图对照及有疑点的局部；测试文字修改并恢复、物件组移动并恢复，隐藏文字/主体检查完整背景与承接面。若支持，导出相关隔离视图；不支持则记为未验证并说明，不伪称执行。遵循官方截图节奏，完成后只在实际修正时再截图。

交付可访问的 Figma Design 文件与画布链接。在线 Design 文件是原生交付；只有实际导出了 .fig 才能称交付本地 .fig 文件。HTML、SVG 或原图附件均不能代替 Design 结果。
