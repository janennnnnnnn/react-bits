# 项目规则结构

在用户任务目录记录实际项目数据，可用 Markdown 表格；不要求用户预先填表。

- 来源：文件链接、页面与母版节点 ID、截图位置。
- 产出矩阵：资源位名称、宽、高、主题、对应母版、输出节点 ID、状态。
- 角色映射：语义角色、源节点 ID、组件/变量来源、允许修改的属性。
- 布局：画面比例类别、固定区域、流动区域、主体锚点、裁切许可、安全边距、文字最大行数和最小字号。
- 长图：模块顺序、重复项来源、模块间距、高度计算方式。
- 主题：语义变量或节点、原值、目标值、替换素材位置、禁止修改的内容。
- 证据：明确要求 / 多模板观察 / 单样本推断；记录推断的适用范围。
- 验收：尺寸与数量、文字溢出、截图检查结果、未解决问题。

按实际母版填写；不要将示例中的占位值用作真实生产规格。若只有单一母版，先用代表性的比例变化验证推断，再复用到同类规格。
