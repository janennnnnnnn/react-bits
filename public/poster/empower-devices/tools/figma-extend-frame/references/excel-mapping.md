# Excel 需求映射

读取真实工作表及表头，按含义建立映射，不要求用户改成固定格式。

| 语义 | 常见表头示例 | 处理 |
|---|---|---|
| 输出标识 | ID、资源位、名称 | 优先保留显式 ID；否则用工作表+行号跟踪 |
| 宽、高 | 宽度、高度、尺寸 | 解析独立列或明确的 1080×1920 等；必须为有效正数 |
| 单位 | 单位 | 未标注时从表头、说明或项目规格确认；不擅自将 cm 当 px |
| 数量 | 数量、份数 | 出现时生成对应份数；没有则每有效行一稿 |
| 组件与布局 | 模板、组件、横竖版、variant | 映射到实际可用组件及属性值 |
| 变量模式 | 主题、mode、配色 | 映射到正确集合的实际模式 ID，不按同名盲选 |
| 内容 | 标题、副标题、CTA、商品 | 映射到实际组件属性或已定位内容节点 |
| 可见性 | 显示按钮、展示价格 | 规范化为布尔，区分空值、false 和 0 |

保留源行号；忽略全空行，区分说明行、表头和数据行。多工作表有明确生产范围时按范围读取；不明时先检查内容再判断。合并单元格只有明确代表分组时才继承组值，不对任意空白前向填充。

公式使用工作簿提供的已计算结果；结果缺失时标记或用受支持工具计算，不把公式文本当作尺寸或文案。保留 SKU、编号的前导零。重复尺寸可能有不同内容，不按宽高去重。

遇到无效尺寸、未知模式或未找到组件属性，记录对应单元格和原因。继续处理不依赖该问题的有效行；不可悄悄回退到其他主题或模板。输出清单至少包含源工作表、行号、输出标识、宽高、模式、节点 ID/链接、状态和问题。
