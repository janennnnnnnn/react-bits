# PAX 海报工作流

## 1. 确认需求

先读取用户已给的需求信息，再讨论需要补充什么文案、素材图（prompt）、组件等。
必须明确的内容有：产品、海报面向目标用户、是否有品牌设计规范、多产品海报确认主次关系，以及需要优先表达什么（例如数量那么就要突出文字，例如功能哪需要考虑拆解官网或已有文档的特点，并将其可视化，需要做好主视觉的场景prompt 编写并和用户确认）。
已有的品牌规则是平台上的，需要读取从 Asset → Picture 查找对应 产品的Logo，依据品牌规则则按 Brand Foundation 的组合规则排列。如果没有品牌/或者给了参考图， 可以逆推提示词并主动拆解参考图的视觉风格、排版、素材风格、语言风格等等，向用户确认需要参考的范围。
确认传播目标、用户、核心目标、发布渠道、语言、核心信息、button及目的链接等等信息。
明确尺寸：发布渠道影响尺寸：若有指定尺寸或文案，以用户要求为准。（社交媒体海报先从 Library → Poster 的 Social media 分类推荐模板和尺寸，同时检查 Asset → Banner 是否有可复用的官方视频。以 LinkedIn 竖版为例，可从 1080 × 1440 开始。该尺寸下可用主标题 72–96 px、辅助文字 32–44 px、按钮 28–36 px 起稿，并在手机预览中验证。主标题优先控制在两行，副标题一句，保留一个主要行动。渠道、语言与文字长度变化时重新估算。）

## 2. 通过 MCP 查资料并核实内容

- 用 `search_design_library` 按产品名查 Asset。优先读取 Knowledge 的产品介绍、Picture 的 Logo 和产品图、Banner 的视频。用 `list_design_assets` 并传入 `{"category":"Poster"}` 查历史海报，打开相关素材链接查看实际内容。
- 用 `search_design_library` 搜索 `kind: "Template"`，从结果选出 Library → Poster 的模板。读取所选条目的 `workflow`，检查预览和 `download`。模板附带的说明用于确认字段、素材路径、交互和渲染方式。用户已有明确模板时直接使用该模板。
- 用 PAX Global 官网及对应产品页核对硬件型号、软件名称、功能、适用范围和下载链接。重点区分软件实际支持的能力和营销表述。规模数字、排名或时间等缺少依据时，请用户补充获批来源。终端设备图必须从官网取得，找不到时请用户补充官方素材。禁止生成替代设备图。 [PAX Global](https://www.pax.com.cn/)
- 记录使用的产品资料、素材链接和待确认项。MCP 或素材链接不可用时，说明具体缺项，并继续使用用户已提供的可核实资料。

## 3. 提交设计计划卡

先参考 Library/poster 或者 Asset 中与受众和场景匹配的历史海报，拆解版式、构图、字体和视觉层级。提供历史设计资产可快速生成的方案。
提供一张带素材标注的构图预览或参考图，并附实际选用素材的预览链接。计划卡逐项写明：
- **方向与版式**：模板、画布尺寸、阅读视觉顺序、主视觉（需求优先要表达什么）、CTA 位置及动效。
- **可编辑内容**：文案字段、文字和组件的位置、可增删或替换的素材、可切换的 Logo。
- **复用资产**：产品文案、Logo、字体、品牌箭头、历史海报参考和视频，附来源与用途。
- **待生成素材**：说明用途、尺寸、构图留白、色彩和风格，给出可交给 Codex Image 2 或即梦的提示词。官方产品图与 Logo 独立保留，以便准确复用和替换。

和用户确认设计方向，并询问要快速静态图、动态 HTML，还是可编辑的 Figma 或 PSD。已明确的交付形式直接沿用。

## 4. 制作、检查与交付
- **快速静态图**：用 Codex Image 2 或已连接的图像工具生成适用画面（没有生图工具的话需要提醒不要自己生差的，提示用户用codex/即梦/提供哪些素材），再用可控排版叠加准确文案与官方资产。按目标像素尺寸导出高清 PNG。
- **动态 HTML**：从所选模板开始制作。交付可编辑 HTML 画布，支持改文案、调整元素位置、增删素材和切换 Logo。已有模板缺少这些操作时，在生成版本中补齐，并实际验证修改后的效果。打包字体、图片和视频，提供预览及可下载 HTML。
- **Figma 或 PSD**：从制作开始保留分层。已有静态设计图，或用户需要多尺寸版本时，按下节调用工具。
- **交付前**：按目标尺寸检查文案与官方素材、裁切、对比度、Logo、字体和链接。HTML 额外检查视频、动效及画布编辑操作。交付成品、使用的素材来源和仍需用户确认的内容。

## 5. 静态图转可编辑源文件与多尺寸适配

对话中出现以下需求时，直接读取 HTML 下载包内对应的 Skill，并按其中的说明执行。静态图转可编辑稿使用 `tools/image-to-frame/SKILL.md`，扩展画布尺寸使用 `tools/figma-extend-frame/SKILL.md`。缺少原图、目标格式或尺寸时，只追问缺项。

1. **静态图转源文件**。用户提供或选定 Codex 生成图，并要求可编辑 Figma、Photoshop 或分层 PSD 时，优先调用 **Image to Frame**。使用原始高清图，附上可用的准确文案、品牌字体和官方 Logo。将文字、Logo、背景、装饰和可替换图片拆为独立图层。验证文字可改、元素可移动、素材可替换。按工具实际支持的格式交付。若只得到 Figma Frame，使用已连接且支持分层 PSD 的工具另行重建和导出 PSD，并在 Photoshop 中验证。无法导出时，明确已完成的格式。
2. **扩展尺寸**。用户要求横版、竖版、社媒多尺寸或其他画布比例时，已有可编辑 Figma Frame 就调用 **Figma Extend Frame**。输入只有静态图时，先通过 Image to Frame 建立可编辑母版。每个尺寸从母版复制，按目标像素和渠道重排版式，检查标题换行、Logo 安全区、CTA 位置和主体裁切。保留母版及各尺寸 Frame。
3. **工具不可用时**。若市场要求登录或当前 Agent 无法取得工具，优先用已连接的可编辑设计工具继续重建。需要账户授权时，只说明所需授权和受影响的步骤。检查实际生成的文件后再报告完成。

## 示例 · Empower Devices

AirLauncher 的 LinkedIn 海报以用户给的「Empower 1 Million+ Devices」「Effortlessly Customize Your Android Devices.」「Download Now!」「Thank You for Being Part of Our Journey!」为起点。先优先确定了产品，查 PAX Global 的 AirLauncher 介绍及视频资源，核实重点的产品功能与下载素材目标，请用户确认活动数字。再查 Asset 的 Picture、Banner 和历史海报视觉风格尽量保持统一，沿用已有的素材/新生类似风格的素材。选用 AirLauncher 相关素材，并按 Brand Foundation 使用 Poppins 和品牌箭头。CTA 可参考 Pinterest 上的按钮样式，通过可用的图转代码工具重建为 HTML 组件。其他任务按实际产品、受众和渠道重新选择素材与方案。

下载 Empower Devices 模板后，可复制 `brief.example.json` 为 `brief.json`，填写已确认的字段，并把字标和 MP4 放入 `assets/`。在解压目录用 Node.js 18 或更高版本运行 `node render.mjs brief.json output`。每版使用新的输出目录，打开 `output/index.html` 查看动效。该脚本完成这个模板的字段替换和本地素材打包。交互编辑、高清截图和分层源文件由所选制作工具完成。
