# Use Cases
## Recommended Scenarios

### English Copy
#### Classic ECR Solution
- Body: At checkout counters in large retail chains, Windows-based ECR systems work seamlessly with payment terminals using a Full Integration model. From well-known integrators such as ACI and DataCap to global brands like Disney, many have adopted this proven solution.

- Body: A single Android smart terminal can handle all payment capabilities. ECR applications and PxRetailer run together on devices such as A920Pro and A3700, enabling dual capability in one device through Full Integration.
