# Features Overview
## Features Overview

### English Copy
- Instant Data Encryption: Immediately encrypts PAN and track data the moment card information is captured by the point of interaction.
- Secure Key Management: Uses DUKPT and other secure mechanisms to ensure a unique key is used for every transaction.
- Isolated Data Transmission: Converts sensitive data into meaningless ciphertext so it cannot be read while passing through merchant networks, POS systems, or the internet.
- Terminal Integrity Protection: Supports only PCI SSC-certified hardware devices with anti-tamper and physical security characteristics.

### 中文文案
- 即时数据加密：在设备采集到卡片信息的瞬间，对 PAN 和磁道数据立即加密。
- 安全密钥管理：采用 DUKPT 等机制，确保每笔交易使用唯一密钥。
- 隔离式数据传输：将敏感数据转换为无意义密文，确保其在商户网络、POS 系统和互联网中传输时不可读。
- 终端完整性保护：仅支持 PCI SSC 认证硬件设备，并具备防拆和物理安全特性。
