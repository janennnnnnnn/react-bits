# Features Overview

## Features Overview

### English Copy

- Exclusive Signing Keys: Each customer uses an exclusive signing key to protect their applications and business interests.
- PCI-Certified HSM Protection: Private keys are generated, stored, and used for signing inside PCI-certified HSMs and are never exposed in plaintext.
- Dual-Control Approval: Customers can designate two approvers to support PCI P2PE dual-control requirements.
- Secure API Integration: Integrate application-signing submissions into your existing systems or development workflows through secure APIs.
- MAXSTORE Automated Signing: Automate app signing with MAXSTORE.
- Backup and Recovery: Working and backup HSMs help protect signing keys and maintain service availability.
- Logs and Auditing: User, key-management, approval, signing, and API operations are recorded for auditing.
- Customer Data Isolation: Customer accounts, signing keys, application files, and operational data remain isolated from one another.

### 中文文案

- 客户专属签名密钥：每位客户使用独立的签名密钥，保护自身应用和业务权益。
- PCI 认证 HSM 保护：私钥在符合 PCI 认证要求的 HSM 内生成、存储并用于签名，全程不以明文形式暴露。
- 双人审批机制：每个签名申请须由两名授权审批人完成审批后方可执行。
- 安全 API 集成：通过安全 API，将应用签名提交集成至客户现有系统或应用开发工作流。
- MAXSTORE 自动签名：配合 MAXSTORE 实现应用自动签名。
- 备份与恢复：通过工作 HSM 与备份 HSM 保护签名密钥并保障服务连续性。
- 日志与审计：记录用户、密钥管理、审批、签名及 API 操作，满足审计需求。
- 客户数据隔离：不同客户的账户、签名密钥、应用文件及操作数据相互隔离。
