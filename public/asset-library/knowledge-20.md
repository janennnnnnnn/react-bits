- Body: Monitor battery usage across different transaction scenarios to analyze device power efficiency.

# Features Overview
## Five Core Test Libraries

### English Copy
- TestUPKeywordLibrary: A keyword library for payment applications, covering end-to-end transaction flows and supporting performance and stability testing.
- TestUPCheck8583Library: Supports ISO 8583 message parsing and validation, ensuring transaction message accuracy and consistency.
- TestUPCheckReceiptLibrary: Supports automatic receipt comparison and verification, improving reconciliation and acceptance efficiency.
- TestUPSecurityTestLibrary: Covers multiple payment security test scenarios to identify risks and strengthen payment security.
- EMV L3 Certification Library: Supports EMV L3 Collis test case automation, accelerating certification verification and improving test coverage.

### 中文文案
- TestUPKeywordLibrary：面向支付应用的关键字库，覆盖端到端交易流程，并支持性能与稳定性测试。
- TestUPCheck8583Library：支持 ISO 8583 报文解析与校验，确保交易报文的准确性与一致性。
- TestUPCheckReceiptLibrary：支持小票自动对比与验证，提升对账与验收效率。
- TestUPSecurityTestLibrary：覆盖多种支付应用安全测试项，用于识别风险并强化支付安全。
- EMV L3 Certification Library：支持 EMV L3 Collis Cases 的自动化测试，加速认证验证并提升测试覆盖率。
