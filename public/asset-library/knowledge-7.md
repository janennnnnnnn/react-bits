# Features Overview
## Features Overview

### English Copy
- Secure & Compliant Storage: All receipts are encrypted and stored in the cloud, with configurable retention periods to meet global audit and data compliance requirements.
- Multi-Channel Delivery: Automatically delivers receipts via NFC, QR codes, email, and more, ensuring 100% user reach.
- Customizable Receipts: Drag-and-drop to design branded receipt templates and embed coupons or WhatsApp support instantly, with no coding required.
- Dual-Mode Receipt Generation: Supports auto-generating digital receipts from transaction data, as well as directly storing original paper receipt images.
- Open API: Standard RESTful APIs and Android SDK enable quick integration with POS, payment, and ERP systems.
- Dual-Admin Management: Provides dedicated admin dashboards for both platform operators and merchants, while end users access receipts via lightweight H5 pages.

### 中文文案
- 安全合规存储：所有收据加密上云，保留周期可配，满足多国审计与数据合规要求。
- 多方式触达：NFC、二维码、邮件等多种方式自动发放，确保凭单 100% 触达用户。
- 收据自定义：拖拽配置品牌凭单模板，一键嵌入优惠券与 WhatsApp 客服，无需开发。
- 双模收据生成：支持从交易数据自动生成电子收据，也支持原始小票图片直存。
- 开放快速集成：提供标准 RESTful API 与 SDK，快速对接 POS、ERP 等系统。
- 双端管理：提供平台与商户双端管理后台，用户通过 H5 页面便捷查看收据。
